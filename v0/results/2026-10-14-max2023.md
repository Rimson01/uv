## 후속 확인

이후 사용자가 같은 Max 세션에서 `v0_auto_check.py`를 실행해 P4 math와
P0 UV coordinate read PASS를 전달했다. 자동 검사에 포함되지 않은 native UI 항목은
NOT RUN으로 표시됐다. JSON 보고서는 사용자 PC 임시 폴더에 생성됐다.

P3 단일 재질 검사에서 처음 OSL Advanced Wood는 경로 미지원으로 표시됐고,
Bitmap으로 변경한 뒤 첫 100개 면의 ID 1과 같은 PNG 경로가 조회됐다.
파일 존재/픽셀 내용/실제 viewport appearance까지 검증한 것은 아니다.

별도 Box + 단일 Unwrap의 Multi/Sub 검사에서 사용자가 전달한 결과:

| face | ID | slot | 조회 결과 |
|---|---|---|---|
| 1 | 2 | 1 | PNG A |
| 2 | 7 | 2 | PNG B |
| 3 | 42 | 3 | PNG C |
| 4 | 4 | 0 | 대응 sub-material 없음 |
| 5 | 6 | 0 | 대응 sub-material 없음 |
| 6 | 2 | 1 | PNG A |

개인 파일 경로는 이 문서에 복사하지 않았다. 비연속 ID의 슬롯 조회는 위 로그와
사용자가 설정했다고 보고한 ID 2/7/42 구성에 부합한다.
새 V1 Workbench Preview는 별도 구현이므로 이 V0 결과를 실행 통과로 승계하지 않는다.

## Workbench 후속 구현 확인

사용자가 Preview 0.1의 Bind와 Mixed IDs 표시를 전달했다. 추가 Listener 로그에서
native M/R/S 모드 전환과 Display 적용/복원 메시지가 확인됐다. 실제 표시 원복의
개별 관찰까지 로그만으로 확정하지 않는다.

Preview 0.2는 배경 API의 존재하지 않는 `getMap` 호출로 실패했다.
공식 Max 2023 문서에 기반하여 0.2.1에서 이를 제거한 뒤 사용자가
“뷰포트에서 면 선택하면 유브이 에디터에서 맵이 바뀌어서 나오네”라고 확인했다.
이것은 face 선택에 따른 자동 배경 전환의 실사용 관찰이다.
수동 이미지 선택/Lock/복원과 0.3 Vertex 추적은 별도 호스트 검증이 남아 있다.

0.3.1의 진단에서 current=6, dropdown-count=9, texMapList-count=8을 확인했다.
texMapList[5]는 UV_Checker, [6]은 스크린샷 Bitmap이며 화면은 UV_Checker를 표시했다.
따라서 관찰된 호스트의 dropdown 인덱스는 texture-list 인덱스보다 1 크다.
0.3.2에서 전환/원복의 인덱스 변환을 함께 수정했으며 수정 후 실제 표시 결과는 미검증이다.
